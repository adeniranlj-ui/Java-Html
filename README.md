# Java-Html

Front-end web projects built with HTML, CSS, and JavaScript.

**Live site:** [https://adeniranlj-ui.github.io/Java-Html/](https://adeniranlj-ui.github.io/Java-Html/). Each project below has a link that opens it in your browser, with no download needed.

## Projects

### [Hoodie Check](hoodie-check/)
A small weather app that fetches the current temperature in San Marcos, TX from the [Open-Meteo API](https://open-meteo.com/) and recommends whether to wear a hoodie.

- **Tech:** HTML, CSS, JavaScript (Fetch API, async/await)
- **Live demo:** [https://adeniranlj-ui.github.io/Java-Html/hoodie-check/](https://adeniranlj-ui.github.io/Java-Html/hoodie-check/)

### [About Me](adeniranlj-_abtme/)
A responsive three-page personal site (Home, Projects, Contact) with a shared navigation bar, a card layout built with Flexbox and Grid, and an embedded contact form.

- **Tech:** HTML, CSS (Flexbox, Grid, responsive design)
- **Live demo:** [https://adeniranlj-ui.github.io/Java-Html/adeniranlj-_abtme/](https://adeniranlj-ui.github.io/Java-Html/adeniranlj-_abtme/)

### [Online Calculator](online-calculator/)
A four-function calculator with input validation (including divide-by-zero handling) and a credit score checker that rates a score from Poor to Excellent.

- **Tech:** HTML, JavaScript, Bootstrap 5
- **Live demo:** [https://adeniranlj-ui.github.io/Java-Html/online-calculator/](https://adeniranlj-ui.github.io/Java-Html/online-calculator/)

### [Temperature Converter](temp-converter/)
Converts temperatures between Celsius and Fahrenheit in both directions.

- **Tech:** HTML, JavaScript, Bootstrap 5
- **Live demo:** [https://adeniranlj-ui.github.io/Java-Html/temp-converter/](https://adeniranlj-ui.github.io/Java-Html/temp-converter/)

### [Web Development Tutor (Chatbot)](chatbot/)
An AI chatbot that answers web development questions. It keeps the conversation history and sends it to a large language model (Google Gemma 3) through the DeepInfra chat completions API.

- **Tech:** HTML, JavaScript (Fetch API, async/await), Bootstrap 5, REST API
- **Run it:** copy `chatbot/env.example.js` to `chatbot/env.js`, add your [DeepInfra](https://deepinfra.com/) API key, then open `chatbot/index.html`. The key file is excluded from the repository by `.gitignore`.
